# منصة الاستثمار المصرية المستقلة

كود التطبيق فقط؛ لا يحتوي على محفظة المستخدم أو بيانات دخوله. لا يغير التطبيق القديم.

## الوظائف
سجل معاملات وحيازات فعلية، تكلفة شراء تشمل الرسوم، أداء إجمالي وصافي، تقييم يدوي محفوظ، نسخة احتياطية واستيراد، تقرير تاريخي موثق، أبحاث وسيناريوهات، مؤشرات من بيانات مستوردة فعلية، أخبار بروابط وتواريخ الناشرين.

## حدود البيانات
الأسعار المحلية لقطة تاريخية يعرض التطبيق تاريخها وليست أسعاراً لحظية. بيانات الصناديق غير المعتمدة موسومة بوضوح. رسوم غير مسجلة تجعل الأداء غير مكتمل. تعرض TradingView بياناتها في إطارات مستقلة ولا تغذي حساب المحفظة. لا توجد عوائد مضمونة.

الأخبار تحدث بمحاولة مجدولة كل 30 دقيقة عبر GitHub Actions؛ الجدولة قد تتأخر، وتعرض الشاشة وقت البيانات وحالة المصادر. التصنيف يعتمد على عنوان الخبر. بيانات المستخدم تحفظ محلياً في متصفحه ولا تنتقل إلى GitHub. استخدم النسخ الاحتياطي عند الانتقال بين الأجهزة.

## التشغيل والاختبارات
Node 22 أو أحدث. npm test يشغل اختبارات الحسابات والحفظ والأخبار والذكاء الاصطناعي وعزل جلسات التقارير. npm start يشغل نسخة محلية. npm run build يجمع ملفات GitHub Pages.

## الواجهة الأصلية المرتبطة بالمشروع المستقل
قوالب HTML الأصلية للمحفظة والأداء والسوق والأخبار والتوصيات والأدوات والتقارير، وبطاقات الأصول الأصلية، مع التنسيقات والخطوط والأيقونات الأصلية. لم تُنقل محركات الحساب أو الحيازات الافتراضية من التطبيق القديم. يربط legacy-adapter.js القوالب بمحرك InvestCore وملفات المشروع الجديد؛ المحفظة العامة تبدأ فارغة وتظل محلية على الجهاز.

تظل القيم غير المتاحة ظاهرة كذلك: لا تُختلق تدفقات مؤسسات أو RSI أو تقييم عادل أو نسب تدقيق أو شهادة شرعية. أدوات البحث والتقييم وحفظ العمليات تستخدم نماذج المشروع الجديد، وتحيل عناصر الواجهة التي ليس لها محرك مستقل إلى أدواته المتاحة. زر الإخفاء يحجب الشاشة مؤقتًا ولا ينشئ قفلًا بكلمة مرور.

يحفظ الأرشيف تقريرًا مستقلًا لكل جلسة. تغيير التاريخ يفرغ التقرير السابق أثناء التحميل، ويمنع الرد البطيء من تغيير الجلسة المختارة. تصدير CSV يأخذ أرقام التقرير المختار وصناديقه وعملاته ومصادره، ولا يأخذ لقطة أسعار اليوم. المقارنة اليومية تستخدم حيازات إغلاق الجلسة السابقة عبر InvestCore ولا تعوض الإغلاق السابق بسعر الافتتاح. تبقى تغييرات الأسعار وحفظ المحفظة منفصلة عن العرض.

## التحليل بالذكاء الاصطناعي
Groq GPT-OSS 120B هو المزود الأساسي المثبت للمحادثة والنشرة المؤرخة. يُستعاد الاتصال تلقائيًا عبر الخدمة الخاصة، ويُحفظ المفتاح كسر إنتاج على الخادم. يبقى اختيار Gemini أو OpenAI اختياريًا؛ فشل Groq لا يغيّر المزود دون اختيار المستخدم. تحلل النشرة عناوين الناشرين والبيانات العامة المؤرخة فقط؛ لا ترسل سجل المحفظة أو بيانات المستخدم. الأرقام المقارنة تحسب حتميًا خارج النموذج؛ ترفض مخرجات النموذج المحتوية على أرقام جديدة أو مصادر غير معتمدة.

تستخدم نشرة Groq مفتاح الخدمة الخاصة نفسه، دون طلب سر إضافي في GitHub. تُحفظ النشرة في قاعدة D1، مع فاصل ست ساعات وسقف أربعة طلبات توليد فعلية يوميًا بتوقيت UTC، واحتساب المحاولات الفاشلة. يمنع القفل المشترك تكرار التوليد المتزامن بين الصفحات. تُحدّث عند فتح التطبيق أو طلب تحديثها؛ لا يمثل ذلك مهمة خلفية مجدولة على الخدمة الخاصة.

يبقى scripts/update-ai.mjs مستخدمًا في مهمة GitHub Actions للنشرات العامة الاختيارية؛ تُقرأ مفاتيحه من Repository Secrets ولا تدخل ملفات Pages. هذا المسار يعيد استخدام النتيجة عند ثبات المدخلات ويحترم فاصل ست ساعات، مع سقف أربعة طلبات يوميًا لـOpenAI. اتصال Groq الأساسي لا يحتاج إلى إعداد هذا المسار. التكلفة والحصة وفق خطة المزود، والفشل يظهر صراحة ولا يتحول إلى نجاح صوري.

أثناء تحميل الأسعار تظهر حالة تحميل صريحة. تلف النسخة المحلية للأسعار لا يمنع محاولة قراءة المصدر المنشور، وفشل التحديث لا يمس المحفظة أو اللقطة الصالحة السابقة. التقارير والرسائل تعرض حالة الفشل وحدود التحديث بالعربية؛ لا تُنشر نصوص أخطاء المزود أو الأسرار.

حقائق الأخبار المنسوبة إلى الناشر يجب أن تطابق عنوان المصدر حرفيًا. لا تدخل أسعار الأسهم إلى نص النموذج؛ تعرض الأرقام الحسابية في قسم مستقل مؤرخ. مُدقِّق العناوين لا يضمن صحة رأي النموذج أو صحة الخبر نفسه. عقد REST موثق في [مرجع Google الرسمي](https://ai.google.dev/api/generate-content).


## الأداء والرسوم والمحادثة — إصدار 2.3
أعيد بناء صفحة الأداء بواسطة performance-engine.js وperformance-ui.js. تتغير النتيجة داخل الصفحة لكل زر فترة، ويقبل محدد التواريخ نطاقاً مخصصاً. تستخدم الحسابات دفتر الحيازات عند حدود الفترة والأسعار المؤرخة والأرشيف المدقق؛ الإيداعات والسحوبات والأرصدة الافتتاحية المضافة تدفقات رأس مال وليست أرباحاً. يستخدم عائد الفترة Modified Dietz، ويظل غير متاح عندما تغيب حدود التقييم أو رأس مال صالح.

thndr-fees.js يفصل رسوم الأسهم عن رسوم الإيداع، وفق صفحات دعم ثندر الرسمية المراجعة في 2026-10-08: 2 ج + 0.1% للوسيط، والرسوم التنظيمية والدمغة وحدودها، مع احتساب الرقابة لكل تنفيذ جزئي. المحافظ الإلكترونية 0.7%؛ Instapay له رسوم شبكة مستقلة خارج رصيد ثندر بحد أدنى 0.5 وأقصى 20 ج. الحاسبة تقديرية؛ يراجع المستخدم رسوم الكشف قبل حفظ القيد. لا يعاد تعديل الرسوم القديمة تلقائياً.

المحادثة والتشخيص وقراءة الصور تستخدم خدمة خاصة https://egypt-investment-ai.maher-elkhateb1.chatgpt.site. Groq محفوظ كسر خادم دائم ويتقدم على اتصال المتصفح المؤقت؛ لا يحتاج إلى إعادة إدخال المفتاح. يمكن للمزودين الآخرين استخدام سر خادم أو cookie مشفرة HttpOnly لمدة 7 أيام. تعود جلسة الاتصال تلقائيًا عبر إطار مصادق، وتُحفظ الرسالة الأولى حتى يستعيد الاتصال. إذا انتهت جلسة حساب Sites فقد يلزم تسجيل دخول المالك؛ هذا مستقل عن ربط مفتاح المزود. لا توجد مفاتيح ضمن مستودع Pages. الصور تتطلب موافقة مستقلة وترجع مسودة للمراجعة عبر Gemini أو OpenAI؛ نموذج Groq المتصل يدعم النصوص.

تحليل التقرير يرسل نوعه وحدود فترته وتصفية الأصول المختارة فقط. لا تُضاف إليه أسعار السوق الحالية أو أخبار فترة أخرى. عند تغيير التقرير تُبدأ محادثة جديدة منعًا لخلط السياق. ملخص المحفظة اختياري وموسوم بحيازات اليوم، ولا يُقدّم كسجل حيازات تاريخي.

يفحص system-audit الواجهة في جميع قوالب الصفحات، الوحدات وملفات البرمجيات والأرشيف، أخطاء التشغيل، وسلامة دفتر الحسابات ومصادر البيانات. يقترح AI إصلاحات محددة من قائمة السماح، يتحقق التطبيق من كل اقتراح، ثم يعيد الفحص مع نسخة استعادة. لا ينفذ AI شيفرة عشوائية أو يغير أموال المستخدم. هذه الفحوص محددة ولا تضمن اكتشاف كل عطل ممكن.

## التقارير الأسبوعية والشهرية وتقويم السوق
التقرير الأسبوعي يجمع التقارير اليومية المدققة من الأحد إلى السبت، والشهري يجمع مكونات التقارير الأسبوعية مع قص حدود الشهر ومنع تكرار الأيام. نسب التغير محسوبة من إغلاق البداية والنهاية، لا من جمع النسب اليومية. تبقى الأسعار أو الأحجام غير الموثقة غير متاحة. يظهر نقص الأرشيف بوضوح، وتُحجب عوائد الأصول التي تحتاج سلسلة معدلة بسبب تغيير وحدة السعر.

يحفظ report-sources إسقاطاً عاماً من المصادر المؤرخة، ويعيد report-review تدقيق كل لقطة. لا يكتب مستورد التقرير القديم فوق تقريرنا المدقق. يرفض مولد التقرير مصدر إغلاق لا يطابق اليوم أو العطلة، ويولّد نشرة عطلة بلا أسعار مصطنعة. يعتمد market-calendar الإجازات التي راجعنا مصادرها، ويعرض أخبار الإجازات والأحداث الجديدة كتنبيهات تحتاج مراجعة. لا يفترض أن التقويم يضم جميع إجازات السنة. أُثبت إغلاق 2026-10-08 واستئناف الجلسات المعتادة يوم 2026-10-11 وفق مصدرين منشورين.

## مراجعة الكود والتنظيف
حُذفت الصفحات والأنماط القديمة التي لا تُحمّلها الواجهة، وقوالب الرأس والتنقل المكررة، ومعالجات الأدوات التي استبدلتها الوحدات الحالية. قوالب الصفحات المستخدمة بقيت كما هي في بنية التطبيق. تُسجل أدوات الأداء والرسوم وقراءة الصور معالجاتها في سجل واحد، وتعتمد نسخة النشر على `index.html` مباشرة، دون ترقيع ملفات JavaScript أو HTML وقت البناء. يفشل البناء بوضوح إذا غاب ملف مطلوب. أُصلح تكرار تحديث عناصر الأخبار الذي كان يعيد تشغيل مراقب التغييرات دون حاجة.

يشمل التحقق اختبارات الحسابات والمصادر وعزل أنواع التقارير وفتراتها، واستعادة الاتصال تلقائيًا، وفحص المتغيرات غير المستخدمة في حزمة الواجهة، واختبار تكامل DOM للأقسام السبعة والأدوات والمحادثة. اختبار DOM يستخدم محاكاة واجهات المتصفح ولا يُعد بديلًا عن تجربة العرض على جهاز فعلي.

## الاتصال المثبت
`ai-connection.js` يتأكد من أصل الخدمة ومصدر كل رسالة، ويستعيد الاتصال دون تمرير أسرار إلى المتصفح. `app-config.json` يحدد الخدمة الخاصة وGroq كمزود أساسي. تُعرض النتيجة بعد فحص الأدلة، ويُعرض التحليل القديم مع حالته وتاريخه إذا تعذر التحديث. لا تُدخل مفاتيح في كود الواجهة أو Git.
