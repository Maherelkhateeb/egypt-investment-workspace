# منصة الاستثمار المصرية المستقلة

كود التطبيق فقط؛ لا يحتوي على محفظة المستخدم أو بيانات دخوله. لا يغير التطبيق القديم.

## الوظائف
سجل معاملات وحيازات فعلية، تكلفة شراء تشمل الرسوم، أداء إجمالي وصافي، تقييم يدوي محفوظ، نسخة احتياطية واستيراد، تقرير تاريخي موثق، أبحاث وسيناريوهات، مؤشرات من بيانات مستوردة فعلية، أخبار بروابط وتواريخ الناشرين.

## حدود البيانات
الأسعار المحلية لقطة تاريخية يعرض التطبيق تاريخها وليست أسعاراً لحظية. بيانات الصناديق غير المعتمدة موسومة بوضوح. رسوم غير مسجلة تجعل الأداء غير مكتمل. تعرض TradingView بياناتها في إطارات مستقلة ولا تغذي حساب المحفظة. لا توجد عوائد مضمونة.

الأخبار تحدث بمحاولة مجدولة كل 30 دقيقة عبر GitHub Actions؛ الجدولة قد تتأخر، وتعرض الشاشة وقت البيانات وحالة المصادر. التصنيف يعتمد على عنوان الخبر. بيانات المستخدم تحفظ محلياً في متصفحه ولا تنتقل إلى GitHub. استخدم النسخ الاحتياطي عند الانتقال بين الأجهزة.

## التشغيل والاختبارات
Node 22 أو أحدث. npm test يشغل اختبارات الحسابات والحفظ والأخبار والذكاء الاصطناعي وعزل جلسات التقارير. npm start يشغل نسخة محلية. npm run build يجمع ملفات GitHub Pages.

## الواجهة الأصلية المرتبطة بالمشروع المستقل
قوالب HTML الأصلية للمحفظة والأداء والسوق والأخبار والتوصيات والأدوات والتقارير، وبطاقات الأصول الأصلية، مع التنسيقات والخطوط والأيقونات الأصلية. لم تُنقل محركات الحساب أو الحيازات الافتراضية من التطبيق القديم. يربط legacy-adapter.js القوالب بمحرك InvestCore وملفات المشروع الجديد؛ المحفظة العامة تبدأ فارغة وتظل محلية على الجهاز.

تظل القيم غير المتاحة ظاهرة كذلك: لا تُختلق تدفقات مؤسسات أو RSI أو تقييم عادل أو نسب تدقيق أو شهادة شرعية. أدوات البحث والتقييم وحفظ العمليات تستخدم نماذج المشروع الجديد، وتحيل عناصر الواجهة التي ليس لها محرك مستقل إلى أدواته المتاحة. زر الإخفاء يحجب الشاشة مؤقتًا ولا ينشئ قفلًا بكلمة مرور.

يحفظ الأرشيف تقريرًا مستقلًا لكل جلسة. تغيير التاريخ يفرغ التقرير السابق أثناء التحميل، ويمنع الرد البطيء من تغيير الجلسة المختارة. تصدير CSV يأخذ أرقام التقرير المختار وصناديقه وعملاته ومصادره، ولا يأخذ لقطة أسعار اليوم. المقارنة اليومية تستخدم حيازات إغلاق الجلسة السابقة عبر InvestCore ولا تعوض الإغلاق السابق بسعر الافتتاح. تبقى تغييرات الأسعار وحفظ المحفظة منفصلة عن العرض.

## التحليل بالذكاء الاصطناعي
يعرض زر المستشار الذكي نشرة بحثية دورية من Gemini أو OpenAI، مع المصادر وتاريخ التوليد وحالة الاتصال. النشرة منفصلة عن المحادثة الفورية الجديدة، التي تتصل بخدمة Gemini الخاصة عبر نافذة الحساب الموثق. يحلل عناوين الناشرين والبيانات العامة المؤرخة فقط؛ لا يرسل سجل المحفظة أو بيانات المستخدم. الأرقام المقارنة تحسب حتميًا خارج النموذج؛ ترفض مخرجات النموذج المحتوية على أرقام جديدة أو مصادر غير معتمدة.

حفظ GEMINI_API_KEY و/أو OPENAI_API_KEY في GitHub Actions Repository Secrets فقط. تستخدم scripts/update-ai.mjs الاعتمادات في الخادم؛ لا تدخل ملفات Pages. حد الطلبات طلب كل ست ساعات لكل مزود وبحد أقصى أربعة طلبات لكل مزود في اليوم وفق UTC، مع إعادة استخدام التقرير السابق عند ثبات المدخلات. تُحسب المحاولات الفاشلة ضمن السقف، ويحفظ العداد في تخزين Actions المؤقت. التكلفة والحصة وفق خطة المزود. الفشل أو غياب المفتاح يظهر صراحة ولا يتحول إلى نجاح صوري. استخدام اشتراك ChatGPT مباشرة يحتاج مسار تفويض رسمي مؤهل؛ المحادثة الجديدة تستخدم Gemini 3.8 Flash؛ النشرة الدورية لها إعدادات مستقلة.

أثناء تحميل الأسعار تظهر حالة تحميل صريحة. تلف النسخة المحلية للأسعار لا يمنع محاولة قراءة المصدر المنشور، وفشل التحديث لا يمس المحفظة أو اللقطة الصالحة السابقة. التقارير والرسائل تعرض حالة الفشل وحدود التحديث بالعربية؛ لا تُنشر نصوص أخطاء المزود أو الأسرار.

حقائق الأخبار المنسوبة إلى الناشر يجب أن تطابق عنوان المصدر حرفيًا. لا تدخل أسعار الأسهم إلى نص النموذج؛ تعرض الأرقام الحسابية في قسم مستقل مؤرخ. مُدقِّق العناوين لا يضمن صحة رأي النموذج أو صحة الخبر نفسه. عقد REST موثق في [مرجع Google الرسمي](https://ai.google.dev/api/generate-content).

أعيد بناء صفحة الأداء بواسطة performance-engine.js وperformance-ui.js. تتغير النتيجة داخل الصفحة لكل زر فترة، ويقبل محدد التواريخ نطاقاً مخصصاً. تستخدم الحسابات دفتر الحيازات عند حدود الفترة والأسعار المؤرخة والأرشيف المدقق؛ الإيداعات والسحوبات والأرصدة الافتتاحية المضافة تدفقات رأس مال وليست أرباحاً. يستخدم عائد الفترة Modified Dietz، ويظل غير متاح عندما تغيب حدود التقييم أو رأس مال صالح.

المحادثة والتشخيص وقراءة الصور تستخدم خدمة خاصة https://egypt-investment-ai.maher-elkhateb1.chatgpt.site. يحفظ مفتاح Gemini كسر خادم أو اتصال متصفح مشفر HttpOnly لمدة 7 أيام بعد اختبار حقيقي لدى Google. لا توجد مفاتيح ضمن مستودع Pages. يلزم إكمال الاتصال بمفتاح صالح؛ نشر الخادم وحده لا يعني نجاح استجابة النموذج. سجل المحادثة يتضمن الأسئلة المتتابعة، وملخص المحفظة لا يرسل إلا باختيار صريح. الصور تتطلب موافقة مستقلة وترجع مسودة قابلة للمراجعة قبل استيراد الحيازات.
