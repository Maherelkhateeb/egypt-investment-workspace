# منصة الاستثمار المصرية المستقلة

كود التطبيق فقط؛ لا يحتوي على محفظة المستخدم أو بيانات دخوله. لا يغير التطبيق القديم.

## الوظائف
سجل معاملات وحيازات فعلية، تكلفة شراء تشمل الرسوم، أداء إجمالي وصافي، تقييم يدوي محفوظ، نسخة احتياطية واستيراد، تقرير تاريخي موثق، أبحاث وسيناريوهات، مؤشرات من بيانات مستوردة فعلية، أخبار بروابط وتواريخ الناشرين.

## حدود البيانات
الأسعار المحلية لقطة تاريخية بتاريخ 6 أكتوبر 2026 وليست أسعاراً لحظية. بيانات الصناديق غير المعتمدة موسومة بوضوح. رسوم غير مسجلة تجعل الأداء غير مكتمل. تعرض TradingView بياناتها في إطارات مستقلة ولا تغذي حساب المحفظة. لا توجد عوائد مضمونة.

الأخبار تحدث بمحاولة مجدولة كل 30 دقيقة عبر GitHub Actions؛ الجدولة قد تتأخر، وتعرض الشاشة وقت البيانات وحالة المصادر. التصنيف يعتمد على عنوان الخبر. بيانات المستخدم تحفظ محلياً في متصفحه ولا تنتقل إلى GitHub. استخدم النسخ الاحتياطي عند الانتقال بين الأجهزة.

## التشغيل والاختبارات
Node 22 أو أحدث. npm test يشغل 61 اختباراً. npm start يشغل نسخة محلية. npm run build يجمع ملفات GitHub Pages.

## واجهة الإصدار 1.1
تصميم عربي داكن بألوان البوابة الأصلية، شريط أسعار مؤرخ، ستة تبويبات سفلية، تحليل الأداء داخل المحفظة، وبطاقات مجمعة للأسهم والصناديق والذهب. حفظ محلي لاختيار البطاقات أو الجدول والوضع الليلي. يحتفظ الاستيراد بتاريخ مصدر الحيازات وبعلامات نقص الرسوم والنقد؛ لا توجد حيازات افتراضية في الكود العام.

## التحليل بالذكاء الاصطناعي
يعرض زر المستشار الذكي نشرة بحثية دورية من Gemini أو OpenAI، مع المصادر وتاريخ التوليد وحالة الاتصال. ليس محادثة فورية. يحلل عناوين الناشرين والبيانات العامة المؤرخة فقط؛ لا يرسل سجل المحفظة أو بيانات المستخدم. الأرقام المقارنة تحسب حتميًا خارج النموذج؛ ترفض مخرجات النموذج المحتوية على أرقام جديدة أو مصادر غير معتمدة.

حفظ GEMINI_API_KEY و/أو OPENAI_API_KEY في GitHub Actions Repository Secrets فقط. تستخدم scripts/update-ai.mjs الاعتمادات في الخادم؛ لا تدخل ملفات Pages. حد الطلبات طلب كل ست ساعات لكل مزود، مع إعادة استخدام التقرير السابق عند ثبات المدخلات. التكلفة والحصة وفق خطة المزود. الفشل أو غياب المفتاح يظهر صراحة ولا يتحول إلى نجاح صوري. استخدام اشتراك ChatGPT مباشرة يحتاج مسار تفويض رسمي مؤهل؛ النسخة الحالية تستخدم موصل OpenAI API المستقل.
